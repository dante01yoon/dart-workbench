# 20편 워크벤치 백엔드 — FastAPI + SSE, 반성 루프, 비용 상한

## 파일
| 파일 | 내용 |
|---|---|
| `mcp_tools.py` | 16편 공시 MCP 서버(`sec16/server_sdk.py`)를 세션 하나로 띄워 두고, 스레드에서 동기 함수처럼 부른다(`call(name, args)`) |
| `workbench.py` | `Workbench(Team)`: 12편 팀 + MCP 도구(공시 · 재무) + 13편 심판(반성 1회) + 비용 상한. 진행을 이벤트(planning → plan → task_start/end → writing → verify → revise → verify 또는 revise_kept → done)로 내보낸다 |
| `server.py` | FastAPI. `GET /api/research?q=&cap=` → SSE 스트림, `GET /` → 확인용 화면. 리서치는 동시에 하나만, 상한은 `COST_CAP`(기본 $0.05) |
| `live.html` | 확인용 화면: 작업마다 진행 막대 + 배지 붙은 보고서(21편에서 React로 다시 만든다) |
| `01_stream.py` | SSE 이벤트를 받아 터미널에 찍는 클라이언트. 인자: 질문, 상한 |

## 실행
```bash
uv run uvicorn server:app --app-dir sec20 --port 8790 > data/server20.log 2>&1 &
uv run python sec20/01_stream.py
uv run python sec20/01_stream.py "카카오 2025년 실적과 사업 위험 요인을 정리해 줘" 0.0005
# 브라우저: http://127.0.0.1:8790/
```

## 실제 결과 (2026-10-17 강의 녹화 실행, 모델 deepseek-v4-flash)
- 기본 상한 $0.05, "카카오 2025년 실적과 사업 위험 요인을 정리해 줘"
  - plan 5.6초: financials · filings.
  - 재무 근거 3개(7.5초, MCP 재무 도구), 공시 근거 4개(96.2초, 근거 추출 모델 호출이 대부분).
  - 심판 1차 지지 6/7($0.0009) → 반성 1회 → 2차 7/7. 전체 173.5초, $0.0011.
  - 보고서 7문장: 매출 8조 991억(전년 7조 8,640억), 영업이익 7,320억(4,953억), 순이익 5,180억(−1,619억에서 흑자 전환), 위험 요인(이자율 · 지분증권 가격 · 환율 · 손해보험 경기 침체).
- 상한 $0.0005: 근거까지 $0.0001 → 보고서 쓰기 호출 뒤 `budget` "$0.0008 > 상한 $0.0005"에서 멈췄다. 청구액은 호출이 끝나야 알 수 있어서 한 번은 넘는다.
- 녹화 전 실행에서 반성 답이 비어 보고서가 0문장(지지 0/0)이 된 적이 있다. 그래서 고친 답이 비면 원래 보고서를 지키고 `revise_kept` 이벤트를 낸다.

## 과제
1. 상한을 아주 낮게 줘서 정말 멈추는지, 얼마나 넘는지 본다.
2. 반성 루프를 끄고 켜서 지지 비율 · 비용 · 시간을 비교한다(남은 문장 수도).
3. 요청 두 개를 동시에 보내서 두 번째가 어떻게 되는지 본다.

풀이와 실측은 `SOLUTIONS.md`.
