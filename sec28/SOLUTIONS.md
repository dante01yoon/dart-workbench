# 28편 과제 풀이 (실측 2026-10-19, 모델 호출 없음)

## 과제 1 — 정규식으로 넓히면 (`solutions/a1_regex_refusal.py`)
| 방법 | 사람 판정과 다른 사례(8개 중) |
|---|---|
| 넓게: `수 없\|어렵\|않습니다` | 1 — q56 2회차("미래 주가를 보장하지 않습니다"로 끝난 투자 분석)를 통과시킨다 |
| 중간: `(확인\|제공\|답변)\S{0,4} ?(수 없\|어렵)` 등 | 1 — 22편 q51("제공해 드릴 수 없습니다", 띄어쓰기 두 번)을 놓친다 |
| 문구 목록(v3) | 0 |
- 넓히면 실패를 통과시키고, 조금 좁히면 띄어쓰기 하나에 놓친다. 그래서 문구는 실제 답에서 하나씩 더하고, 테스트가 양쪽을 지킨다.

## 과제 2 — q49 정답 키 조이기 (`solutions/a2_tighten_q49.py`)
- 조인 키: "톡비즈" + ("포털비즈" · "플랫폼기타" · "플랫폼 기타" 중 하나) — 공시의 플랫폼 부문 구성 세 가지.
- 저장된 답 6개에서 바뀐 판정은 0개. 22편 처음 버전과 10/18 1회차는 도구에 없다고 하면서 "일반 지식"으로 톡비즈 · 포털비즈를 다 적어 조인 키도 통과한다.
- 키를 조여도 기억으로 쓴 답은 못 거른다 → 출처 기준(27편 R5)과 판사(29편)가 필요한 자리.

## 과제 3 — 새 버그와 두 답 (`solutions/a3_new_bug.py`)
- 더하기를 `a + b + 1`로 망가뜨리면 실패 테스트는 test_add 1개, 통과 5개.
- ① 더하기만 고친 답: FAIL_TO_PASS 1/1 · PASS_TO_PASS 5/5 → 통과.
- ② add만 남기고 나머지 함수를 지운 답: 테스트 파일이 다른 함수를 불러오다 깨져 FAIL_TO_PASS 0/1 · PASS_TO_PASS 0/5 → 실패. 고친 줄만 보면 맞아 보이는 답을 PASS_TO_PASS가 잡는다.
