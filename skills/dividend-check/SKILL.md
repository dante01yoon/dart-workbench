# dividend-check

반드시 지킬 출력 표식: 첫 줄은 "[배당 점검]"

1. dividends 결과에서 보통주 '주당 현금배당금(원)', '(연결)현금배당성향(%)', '현금배당금총액(백만원)'의 당기·전기 값을 옮긴다.
2. 배당성향 = 현금배당금총액 ÷ (연결)당기순이익 × 100 으로 직접 다시 계산해 공시 값과 비교한다(차이 0.5%p 이내면 일치).
3. 전기 대비 주당배당금 증감률을 계산한다.
4. 출력 형식: 첫 줄 "[배당 점검]", 이어서 '공시 배당성향 / 재계산 / 일치 여부 / 주당배당금 증감률' 네 줄.
