# 25편 과제 풀이 (실측 2026-10-19, 모델 호출 없음)

## 과제 1 — held-out 서술 문항 2개 (`solutions/a1_fill_heldout.py`)
- 은행의 서술 문항(q44~q50)은 13편 · 24편에서 이미 돌려 봐서 held-out에 넣을 수 없다 → 사업보고서 문단(`data/rag/chunks.jsonl`)에서 새로 만든다.
- 「현대자동차 차량부문의 주요 원재료와 매입처는?」 정답 낱말 [모듈] · [현대모비스] — 「II. 사업의 내용 > 3. 원재료 및 생산설비」 문단 6개 중 실제로 있는지 확인.
- 「카카오는 이자율변동위험이 주로 어디서 생긴다고 설명하나?」 정답 낱말 [변동금리] — 「위험관리 및 파생거래」 문단에 "주로 변동금리부조건의 차입금과 예금에서 발생".
- 두 문항 모두 개발 문항과 같은 질문 아님(twin 검사) → held-out 유형: 보고서형 7 · 숫자 3 · 사실 2 · 전년 대비 2 · 회사 비교 2 · 거절 2 · 서술 2 · 함정 1 · 근거 없음 1, 전체 69문항 → `eval/questions_v2_a1.jsonl`.
- 이걸 하려고 `01_collect.py`의 항목 낱말에 "외환" · "이자율"을 넣었다. 없으면 카카오 이자율 질문이 개발 q47(카카오 외환위험)과 같은 질문(항목 "위험")으로 잘못 묶인다.

## 과제 2 — held-out 잠그기 (`solutions/a2_lock.py`)
- 실행 기록 30개(`data/*.json*`, 25편이 만든 파일 제외)를 전부 뒤졌다 → **q35 「카카오 연구개발비용은 전년 대비 늘었나?」가 4편 컨텍스트 실험 기록(`data/context_runs.json`, sec04/01_context.py)에 이미 있었다.** 은행에서 "아직 안 쓴 문항"으로 골랐지만 실제로는 돌려 본 문항이었다 → 개발로 옮긴다.
- 남은 held-out 19문항의 지문(sha256) `9d2bb8d268a09e77…`를 `eval/heldout_v2.sha256`에 남기고, 고친 시험지는 `eval/questions_v2_locked.jsonl`(개발 48 + held-out 19).
- 배운 점: "안 쓴 것 같다"는 기억이 아니라 기록 검색으로 확인한다. 다음 편부터는 `questions_v2_locked.jsonl`을 쓴다.

## 과제 3 — 시험지 v2 한 번 돌리는 값 (`solutions/a3_cost_estimate.py`)
- 24편 실행 기록(같은 날 40문항)의 유형별 평균: 숫자 $0.0072 · 230초, 사실 $0.0081 · 199초, 전년 대비 $0.0044 · 81초, 회사 비교 $0.0055 · 97초, 서술 $0.0060 · 94초, 거절 $0.0001 · 2초, 근거 없음 $0.0086 · 230초. 보고서형 · 함정은 기록이 없어 전체 평균($0.0059 · 137초).
- **v2 67문항 한 번 ≈ $0.42 · 4개 동시에 약 43분.** 같은 문항이 10/17에는 문항당 $0.0009였으니, 날마다 값이 달라질 수 있다 — 큰 실행 전에는 한두 문항으로 먼저 값을 잰다.
