# 10편 출처 달기 · 숫자 대조 · 거절, 그리고 에이전트형 RAG

## 파일
| 파일 | 내용 |
|---|---|
| `cite.py` | 공용: 9편 맥락 하이브리드 검색, 문장마다 [번호] 출처를 다는 답 지시문(근거 없음 · 투자 권유 거절은 정해진 한 줄), 문장 인용 확인, 금액을 원 단위로 읽기, 재무 API(주요 계정 · 연결) 값 · 재작성 전년 값, 0.1% 대조 |
| `01_cited.py` | 질문 4개(숫자 · 서술 · 근거 없음 · 투자)로 답 · 인용 확인 · 재무 API 대조 보기 |
| `02_eval.py` | 29문항 성적표(숫자 12 · 서술 7 · 근거 없음 5 · 투자 권유 5) → `data/rag/cite_eval.json` |
| `03_agentic.py` | 같은 11문항(전년 대비 8 · 회사 비교 3)을 RAG 한 번 vs 에이전트(공시 검색 · 재무 API 도구) → `data/rag/agentic.json` |
| `04_cite_web.py` | 원문 하이라이트 화면 http://127.0.0.1:8810 — 답 문장별 확인 결과 + 인용 원문에서 숫자 칠하기 + 종류별 성적표 |

## 실행
9편까지 돌려 `data/rag/`에 청크 · `context.jsonl` · `emb_ctx.npy`가 있어야 한다. 재무 API는 `.env`의 `DART_API_KEY`를 쓴다.
```bash
uv run python sec10/01_cited.py
uv run python sec10/02_eval.py
uv run python sec10/03_agentic.py
uv run python sec10/04_cite_web.py
```
비용은 01 $0.001, 02 $0.01, 03 $0.01 안팎이다.

## 과제
1. 지시문에서 거절 규칙(3 · 4)을 빼고 근거 없음 · 투자 10문항의 답을 비교한다.
2. 숫자 질문에 재무 API 값을 발췌 하나로 함께 넣고 재무 API 일치 · 인용 확인을 잰다.
3. 에이전트에 배당 도구(dividends)를 더하고 배당 문항을 다시 푼다.
