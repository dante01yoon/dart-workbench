# 10편 과제 풀이 (실측 2026-10-13)

## 과제 1 — 거절 규칙 빼기 (`solutions/a1_no_rules.py`)
| 지시문 | 정해진 거절 문구로 답한 수(근거 없음 5 + 투자 5) |
|---|---|
| 규칙 있음(본편) | **10/10** |
| 규칙 3 · 4 뺌 | 0/10 |

- 규칙을 빼도 Flash는 숫자를 지어내지는 않았다. "제시된 발췌에는 … 없습니다", "판단할 수 없다"처럼 대부분 사양했지만 말투가 매번 달라 프로그램이 거절인지 셀 수 없다. 한 문항은 빈 답이었다.
- 규칙이 있을 때도 "카카오 주가 내년에 오를까?"는 투자 권유 거절 대신 근거 없음으로 답했다. 둘 다 거절로 세지만, 종류를 나눠 보려면 지시문 예시를 더 줘야 한다.

## 과제 2 — 재무 API 값을 발췌로 함께 넣기 (`solutions/a2_api_source.py`, 숫자 12문항)
| 발췌 | 재무 API 일치 | 인용 확인(문장) |
|---|---|---|
| 본문만 | 10/12 | 16/17 |
| 본문 + API 한 줄 | **11/12** | 14/15 |

- API 값을 함께 주면 하나 더 맞았다. 그래도 12개를 다 맞히지는 못했다. 모델이 본문 표의 숫자를 고르면 API 줄을 쓰지 않는다.
- 본편 녹화(본문만)는 11/12였다. 같은 설정도 실행마다 10~11개로 흔들린다.

## 과제 3 — 배당 도구 더하기 (`solutions/a3_dividend_tool.py`)
| 문항 | 본편 도구(검색 + 주요 계정) | + 배당 도구 |
|---|---|---|
| SK하이닉스 주당 배당금 전년 대비 | ✅ 검색 1번 | ❌ dividends(SK하이닉스, **2024**) |
| 현대자동차 주당 배당금 전년 대비 | ✅ 검색 1번 | ✅ dividends(현대자동차, 2025) |
| SK하이닉스 · 삼성전자 2025년 주당 배당금 비교 | ❌ 검색 2번 | ✅ dividends 2번 |

- 회사 비교는 배당 도구가 바로 풀었다. 대신 "전년 대비"에서 2024년 보고서를 부르면 당기가 2024년이라 2025년 배당이 빠진다. 도구 설명에 "전년 대비는 올해(2025) 보고서의 전기 칸을 쓴다"처럼 연도 고르는 법을 적어 줘야 한다.
