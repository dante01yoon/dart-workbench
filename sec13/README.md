# 13편 인용 검증기 — 원문 · 숫자 · 심판, 그리고 심판 시험

## 파일
| 파일 | 내용 |
|---|---|
| `verify.py` | 원문 일치(글자 그대로) · 숫자 일치(조 · 억 · 백만원 · 원을 원 단위로, ±0.1%, 연도 제외) · LLM 심판(JUDGE) · 보고서 문장 배지(인용을 출처와 함께 심판에게) |
| `01_badges.py` | 팀 보고서 하나를 근거 단위 · 문장 단위로 확인 |
| `02_eval.py` | 20문항 루브릭: 정답 · 출처 단 문장 · 인용 원문 일치 · 심판 지지 · 비용 · 시간 → `data/team_eval.json` |
| `03_calibrate.py` | 심판 시험: 맞는 쌍 16 + 숫자 바꾼 쌍 8 + 인용 바꾼 쌍 8, 심판과 숫자 규칙의 정답률 |
| `04_report_web.py` | 인용 배지 보고서 http://127.0.0.1:8813 |

## 실행
```bash
uv run --group frameworks python sec13/01_badges.py
uv run --group frameworks python sec13/02_eval.py
uv run --group frameworks python sec13/03_calibrate.py
uv run --group frameworks python sec13/04_report_web.py
```

## 실제 결과 (2026-10-13 강의 녹화 실행)
- 01(삼성 vs SK): 근거 14개 모두 원문 · 숫자 일치. 보고서 6문장 중 심판 지지 4. 당기순이익 문장은 심판이 "절사"라며 부족이라 했지만 45조 2,068억은 맞다 — 심판 오판. 환율 문장은 SK하이닉스 인용에 "주요 위험 요인"이 없다는 지적 — 맞는 지적.
- 02(20문항): 정답 20/20(숫자 4 · 전년 대비 3 · 회사 비교 3 · 서술 4 · 사실 2 · 근거 없음 2 · 투자 권유 2), 출처 단 문장 76/78, 심판 지지 64/78, 인용 원문 일치 114/117, $0.049, 문항당 75초, 빈 답 다시 부름 9번.
- 03(심판 시험):

| 종류 | 수 | 심판 정답 | 숫자 규칙 정답 |
|---|---|---|---|
| 맞는 쌍 | 16 | 6 | 13 |
| 숫자 바꿈 | 8 | 8 | 2 |
| 인용 바꿈 | 8 | 8 | 5 |

  심판은 망가뜨린 쌍을 다 잡았지만 맞는 쌍을 너무 많이 거절했다(이 시험은 출처 없이 인용만 줘서 "연도 · 회사가 없다"). 그래서 문장 배지에는 출처를 함께 넘긴다. 숫자 바꿈은 첫 숫자를 바꿔 대부분 연도(2025 → 5025)가 바뀌었고, 숫자 규칙은 연도를 빼고 보므로 놓쳤다(과제 3에서 금액을 바꿔 다시 잰다).
- 배지 화면: 표에 단위 없이 백만원 숫자만 있는 공시 인용은 숫자 규칙이 금액으로 읽지 못해 "숫자 불일치"로 나온다.

## 과제
1. 심판 지시문에서 단위 규칙을 빼고 같은 쌍으로 다시 잰다.
2. 같은 쌍을 세 번 물어 판정 흔들림과 다수결 정답률을 잰다.
3. 연도 대신 금액을 바꾼 쌍으로 숫자 규칙과 심판을 시험한다.
