# 8편 키워드 검색 BM25와 하이브리드, 재정렬

## 파일
| 파일 | 내용 |
|---|---|
| `search.py` | 공용: 한국어 2글자 토큰(bigram), BM25 직접 구현, 회사 필터 키워드·벡터 검색, RRF 하이브리드, Flash 재정렬 |
| `01_bm25.py` | 7편 청크로 BM25 색인 + 질문 하나 시험(띄어쓰기 토큰 vs 2글자 토큰) |
| `02_compare.py` | 검색 4종 성적표: 원래 질문 · 말 바꾼 질문(q_para) 각 38개, 회사 필터 → `data/rag/compare.json` |
| `03_rank_web.py` | 순위 디버그 화면 http://127.0.0.1:8808 — 문항마다 네 방식의 상위 10개, 정답 조각 ✅ |

## 실행
7편 `01_chunks.py`·`02_embed.py`를 먼저 돌려 `data/rag/`(청크·벡터)가 있어야 한다.
```bash
uv run python sec08/01_bm25.py
uv run python sec08/02_compare.py
uv run python sec08/03_rank_web.py
```
02는 재정렬 때문에 Flash를 76번 부른다(병렬 4, 12분 안팎, 약 $0.14).

## 실제 결과 (2026-10-12 강의 녹화 실행, 회사 필터)
| 방식 | 원래 질문 recall@5 / MRR@10 | 말 바꾼 질문 recall@5 / MRR@10 |
|---|---|---|
| 키워드 BM25 | **0.974** / 0.824 | 0.789 / 0.566 |
| 벡터 | 0.474 / 0.352 | 0.395 / 0.298 |
| 하이브리드 RRF(c=60) | 0.763 / 0.546 | 0.684 / 0.481 |
| 하이브리드 상위 20 → 재정렬 | 0.921 / 0.794 | **0.868** / 0.796 |

- 색인: 청크 3,948개 → 서로 다른 2글자 토큰 49,320개, 0.4초. 7편 벡터가 놓친 "삼성전자 2025년 연결 영업이익"을 BM25는 3위로 찾았다.
- 숫자·고유명사가 많은 공시에서는 BM25가 강하다. 약한 벡터와 섞은 하이브리드는 오히려 BM25보다 낮다.
- 말을 바꾸면 BM25가 떨어지고, 재정렬이 가장 잘 버틴다. 재정렬 비용 $0.0786 + $0.0603.
- 주의: 평가 질문 초안은 원문을 보며 만들었다(키워드 검색에 유리). 말 바꾼 질문 점수를 더 믿는다.
- 녹화 전 같은 코드 실측은 재정렬만 0.895(원래)로 달랐다. 재정렬은 실행마다 조금씩 흔들린다.

## 과제
1. 토큰을 띄어쓰기 · 2글자 · 3글자로 바꿔 BM25 성적을 잰다.
2. RRF의 상수 c와 키워드 가중치를 바꿔 하이브리드가 BM25를 넘을 수 있는지 잰다.
3. 재정렬 후보를 하이브리드 대신 BM25 상위 20개에서 뽑는다.
