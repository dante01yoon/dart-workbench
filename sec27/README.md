## "근거 없음"의 기준 — 공시만으로 정했다
- 26편 기록: 2027 매출 전망 질문에 뉴스 숫자 두 개(821조 · 957조, 한 답 안에서 서로 다름), 카카오 2026년 3분기 영업이익에 증권사 전망(2,495억)을 실적처럼, 신차 출시일에 "출시 예정" 보도를 답으로 냈다.
- 이유: ① 정답 키가 공시(OpenDART)에서 나온다 ② 뉴스 속 전망은 날마다 바뀌고 서로 달라 정답을 고정할 수 없다 ③ 전망은 사실이 아니다.
- 예외: 질문이 뉴스를 직접 물으면(예: n17 "최근 관세 관련 뉴스를 같이 정리해 줘") 뉴스를 근거로 써도 된다.

## 면접 질문
1. "1~5점 척도 대신 예/아니오를 쓰는 이유는?" → 3점과 4점의 경계가 사람마다 달라 판정이 흔들리고 가운데로 숨기 쉽다. 예/아니오는 결정을 강제하고 빠르다. 나아짐은 작은 예/아니오 검사 여러 개로 본다.
2. "'좋은 답'처럼 모호한 품질을 어떻게 잴 수 있는 기준으로 바꾸나요?" → 실패를 읽고 유형을 찾는다 → 유형마다 예/아니오 질문 + 적용 대상 + 통과 · 실패 예 → 코드로 잴 수 있으면 코드, 아니면 판사.
3. "정답 기준이 애매한 질문은 누가 어떻게 정하나요?" → 제품의 약속(공시 기반 리서치)에서 정하고, 기록으로 확인하고, 예외는 기준 문장에 적는다.

## 과제
1. 25편에서 뺀 "자사주 정책 정리" 질문을 예/아니오 기준 4~5개로 쪼개 26편 카카오 자사주 답(n11)에 적용한다.
2. 기준 R7 "질문이 뉴스를 묻지 않았다면 뉴스를 근거로 쓰지 않았나?"를 더하면 몇 문항이 바뀌는지 센다.
3. 모두 통과 비율을 가장 많이 끌어내리는 기준을 하나씩 빼 보며 찾는다.
