# 27편 과제 풀이 (실측 2026-10-19, 모델 호출 없음 — 26편 기록을 읽는다)

## 과제 1 — 열린 질문 쪼개기 (`solutions/a1_split_question.py`)
"자사주 정책 정리"를 기준 5개로 나눠 n11(카카오 2025년 자사주 소각했어?) 답에 적용:
| 기준 | 판정 |
|---|---|
| 소각 여부를 답했나? | 예 |
| 소각 수량(주)을 공시 숫자로 답했나? | 예(220만 2,644주) |
| 취득(매입) 여부를 답했나? | 아니오 |
| 다음 해 소각 결의(1,420,723주)를 짚었나? | 예 |
| 근거가 공시인가(모든 문장이 사업보고서 인용)? | 아니오 — 뉴스 인용 문장이 있다 |
- "정책을 잘 정리했나"는 사람마다 다르지만, 쪼갠 다섯 질문은 누가 봐도 같은 답이 나온다.

## 과제 2 — 뉴스 근거 기준 R7 (`solutions/a2_news_rule.py`)
- 뉴스를 근거로 쓴 답 11개 중 질문이 뉴스를 물은 것은 1개(n17)뿐. R7을 더하면 10개가 아니오, 그중 지금 정답 처리된 답이 5개(q45 q54 n19 n24 q50)다.
- 26편 전체에 R7을 걸면 모두 통과가 크게 떨어진다. 뉴스를 보조 근거로 허용할지는 제품 결정이라 v1에는 넣지 않았다(R3은 "근거 없음" 문항에만 공시 기준을 적용).

## 과제 3 — 끌어내리는 기준 (`solutions/a3_drag.py`)
- 모두 통과 40/53. 하나씩 빼면: R1 빼면 45(+5) · R3 빼면 43(+3) · R2 빼면 42(+2) · R4 · R5 빼면 40(+0).
