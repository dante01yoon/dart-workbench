- 표본이 작다(2번씩). "흔들림"은 "v1에서도 떨어질 수 있다"까지만 말한다.

## 과제 3 — 이력서 문장 검사기 (`solutions/a3_resume_check.py`, 모델 호출 0)
| 문장 | 결과 | 걸린 이유 |
|---|---|---|
| 평가 파이프라인(67문항 · 53/53 · TPR 5/5 · 57~100%) | 통과 | |
| 회귀 관문(4~5초 · 회귀 5문항 차단) | 통과 | |
| 개선 한 바퀴(0/6 → 5/6 · 관문이 3문항 하락을 잡아 병합 안 함) | 통과 | |

- "95%"는 숫자 출처 검사만으로는 **통과**한다 — 기록에 "95% 구간"이라는 글자가 있어서다. 숫자가 기록에 있는지가 아니라 **무엇의 몇 개 중**인지를 봐야 걸린다(분모 검사).
