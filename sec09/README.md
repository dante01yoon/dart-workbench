# 9편 조각에 맥락 붙이기(Contextual Retrieval)와 비교 질문 나눠 찾기

## 파일
| 파일 | 내용 |
|---|---|
| `context.py` | 공용: 맥락 지시문, Flash 호출, 섹션 본문(앞 6,000자) 모으기, 조각 하나의 맥락 문장 만들기(빈 답이면 3번까지 다시) |
| `01_context.py` | `--demo N`: 현대자동차 매출 표 조각 N개만 만들어 보기 / 옵션 없이: 3,948개 전부(동시 16개, 이어서 돌기) → `data/rag/context.jsonl`, `context_stats.json` |
| `02_eval.py` | 키워드 · 벡터 · 하이브리드를 맥락 없이 / 맥락 붙여서 잰다(원래 질문 · 말 바꾼 질문 38개씩, 회사 필터) |
| `03_cross.py` | 회사 간 비교 질문 8개: 한 번에 · 규칙 분해 · LLM 분해 → `data/rag/cross.json` |
| `04_cards_web.py` | 비교 카드 화면 http://127.0.0.1:8809 — 회사별 하위 질문과 합친 상위 10개 안의 그 회사 조각(순위, 정답 ✅) |

## 실행
7편 `01_chunks.py`·`02_embed.py`를 먼저 돌려 `data/rag/`가 있어야 한다.
```bash
uv run python sec09/01_context.py --demo 2
uv run python sec09/01_context.py
uv run python sec09/02_eval.py
uv run python sec09/03_cross.py
uv run python sec09/04_cards_web.py
```
01 전체 실행은 Flash를 3,948번 부른다(약 46분, $2.73). 중간에 멈춰도 다시 실행하면 남은 조각만 돈다.
02는 처음 한 번 맥락 붙인 조각을 다시 임베딩한다($0.06).

## 실제 결과 (2026-10-13 강의 녹화 실행)
맥락 문장 만들기(미리 실행): 조각 3,948개 · 입력 16,273,283 · 출력 2,441,560토큰 · $2.731 · 45.9분. 첫 실행에서 빈 답 2개가 나와 다시 만들었다.

| recall@5 | 원래 질문 키워드 / 벡터 / 하이브리드 | 말 바꾼 질문 키워드 / 벡터 / 하이브리드 |
|---|---|---|
| 맥락 없음 (8편) | 0.974 / 0.474 / 0.763 | 0.789 / 0.395 / 0.684 |
| 맥락 붙임 | 0.974 / **0.763** / **0.895** | **0.842** / **0.658** / **0.816** |

| 비교 질문 8개 | 모든 회사 확보 | 회사별 평균 (상위 10) |
|---|---|---|
| 한 번에 | 3/8 | 0.53 |
| 규칙 분해 | 5/8 | 0.72 |
| LLM 분해 | 5/8 | **0.88** |

- 맥락 문장은 숫자뿐인 표 조각에 "어느 회사 · 어느 표"라는 이름표를 달아 벡터 검색을 크게 올렸다. 키워드 검색도 말 바꾼 질문에서 올랐다.
- 녹화의 `--demo 2`에서 두 번째 조각은 맥락 문장 대신 상담원처럼 "무엇을 도와드릴까요"류로 답했다. 저장된 전체 결과에서 같은 말투를 찾아 보니 3,948개 중 1개였다. 모델이 만든 결과는 열어 보고 확인한다.
- 비교 질문은 회사별로 나눠 찾아야 근거가 고르게 모인다. 회사가 넷이면 한 회사에 돌아가는 자리가 줄어 놓치기도 한다(영업이익률 질문의 삼성전자).
- 원래 방법(Anthropic, 2024)은 문서 전체를 함께 넣지만, 사업보고서는 80만 자라 같은 섹션 앞 6,000자만 넣었다.

## 과제
1. 모델 문장 대신 "회사 연도 사업보고서 · 섹션 경로" 한 줄만 붙여 벡터 성적을 잰다.
2. 맥락 붙인 하이브리드 상위 20개에 8편 재정렬을 건다.
3. 비교 질문의 LLM 하위 질문을 키워드 대신 맥락 붙인 하이브리드로 찾는다.
